# T.R. Prajapati

Portfolio site for **T.R. Prajapati**, an A Class government contractor based in Anand, Gujarat.

Content and project photographs come from the existing company archive.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
